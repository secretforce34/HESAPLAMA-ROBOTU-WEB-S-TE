# Robot resimleri

Her robotun kartındaki yuvarlak resim bu klasörden gelir: `<slug>.webp` (ya da `.png` / `.jpg`).
Örnek: `kredi-hesaplama.webp`. Kare (512×512) olmalı, asıl nesne ortada durmalı; resim daire biçiminde kırpılır.
Resmi olmayan robotta kartta geçici olarak `meta.ts` içindeki emoji gösterilir.
